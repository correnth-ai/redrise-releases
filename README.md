# RedRise — Beta oficial (Windows 11 x64)

Este repositório distribui somente os instaladores do **RedRise** e a documentação de uso. O código-fonte não fica aqui.

- **Baixar:** [última versão](https://github.com/correnth-ai/redrise-releases/releases/latest). Use o arquivo
  `redrise-desktop-<versão>-windows-x64.exe` e confira o SHA-256 em `SHA256SUMS.txt`.
- **Como instalar e usar:** [TUTORIAL.md](TUTORIAL.md).
- **Atualizações:** o próprio RedRise avisa quando há versão nova e confere a assinatura do pacote antes de instalar.

O instalador ainda não tem assinatura de código (Authenticode); o Windows pode mostrar um aviso ao abri-lo.
